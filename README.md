# SysGuard

SysGuard is a lightweight monitoring tool designed for Linux systems.

If you have a server, a remote computer, or a machine that runs continuously, SysGuard allows you to monitor it remotely and keep track of important system events.

## Features

* 🖥️ **System monitoring**

  * CPU usage
  * RAM usage
  * Disk usage
  * System uptime

* 🔐 **Security monitoring**

  * SSH login attempts
  * Successful SSH logins
  * Failed authentication attempts
  * Suspicious activity detection

* 📋 **Log monitoring**

  * Monitor important system logs
  * Detect new security-related events
  * Filter relevant events automatically

* 📡 **Remote notifications**

  * Receive alerts when an important event occurs
  * Telegram notifications
  * Customizable alerts

* ⚙️ **Lightweight**

  * Designed to run in the background
  * Low resource consumption
  * Built specifically for Linux

## Goals

The main goal of SysGuard is to provide a simple way to monitor a Linux machine remotely without requiring a heavy monitoring platform.

The project is also intended to be a practical cybersecurity and systems programming project.

## Technologies

* **C++** — Core application
* **Linux** — Target operating system
* **Git / GitHub** — Version control
* **Telegram Bot API** — Remote notifications
